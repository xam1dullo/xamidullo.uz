# Design System — xamidullo.uz (Linear / Raycast / Vercel Precision Engineering)

## 1. Aesthetic Direction & Persona
- **Subject**: Personal engineering portfolio & technical publication of **Xamidullo Xudoyberdiyev** (Senior Software Engineer at Ucell · Backend Architecture, High-Load Microservices, DevOps, Node.js Mentor).
- **Aesthetic Persona**: **Dark-First Precision Engineering & Architectural Bento** (inspired by Linear, Raycast, Vercel, and Stripe Product Engineering).
- **Liveliness Dials**:
  - `ENERGY: 4/5` — Deep Carbon Obsidian surfaces (`#07080C`), Electric Indigo (`#818CF8`) & Soft Violet (`#C084FC`) ambient illumination, and interactive mouse-tracking specular spotlights.
  - `RHYTHM: 4/5` — Multi-dimensional Bento grids paired with live architectural topology schematics and telemetry HUDs.
  - `MOTION: 3/5` — Smooth compositor reveals, magnetic CTAs, real-time 2D topology canvas packets, and full `prefers-reduced-motion` support.

## 3. Typography (Zero Bookish Serif — Pure Modern Tech)
- **Display & Headings (`--display`)**: `Plus Jakarta Sans` (`600–800`), razor-sharp geometric forms, tight tracking (`-0.03em` to `-0.045em`).
- **Body & UI (`--sans`)**: `Inter` (`400–600`) with OpenType features (`"cv02", "cv03", "cv04", "cv11"`).
- **Technical Metadata, Schematics & Code (`--mono`)**: `JetBrains Mono` (`400–700`) with `font-variant-numeric: tabular-nums` and a strict `0.72rem` minimum floor.

---

## 4. Architectural Bento & Visual Schematics
- **Hero Engineering Command Dossier**: Windowed topology terminal with live 2D node mesh (`XH/SYSTEMS` core + `BACKEND`, `PRODUCT`, `INFRA`, `DATA`), portrait status badge, and real-time latency/throughput/memory HUD.
- **Metrics 4-Card Bento Grid**: Elevated specular cards with gradient tabular counters (`4+ yil`, `3×`, `90%`, `50%`).
- **Featured Project Case-Study Bento Cards**: Two-column architectural showcase where the left side presents the product context & stack, and the right side renders a **Visual System Topology Blueprint** (`N01 → N02 → N03 → N04`) and a **3-Cell Impact Metrics HUD** (`< 60ms`, `3.2×`, `99.9%`).
- **3-Column Blog Bento Cards**: Technical articles presented as specular Bento cards with reading-time pills, tag badges, and interactive hover illumination.
